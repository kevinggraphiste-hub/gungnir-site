Guide de démarrage

De « je découvre » à « il connaît mon métier ».

Quatre étapes, environ trente minutes pour les trois premières. La quatrième se fait tranquillement, à votre rythme.

Seule la première étape change selon votre point de départ : l'essai en ligne, ou l'installation chez vous. Les étapes 2 à 4 sont identiques dans tous les cas.

Étape 1 · Choisir son point de départ
Le plus simple · 5 minutes

Essai en ligne, 14 jours

Allez sur gungnir.scarletwolf.cloud et choisissez « Essai 14 jours ». Vous donnez une adresse email (ou OAuth Google / GitHub), rien d'autre. Pas de carte bancaire, pas de paperasse.

Quatre modèles d'IA sont déjà offerts pendant l'essai (Llama, Mistral, Gemini Flash, Claude Haiku via OpenRouter). C'est largement suffisant pour vous faire un avis sérieux sur vos vrais dossiers.

Pour qui : tester sans rien installer, vérifier que Gungnir couvre votre besoin, démarrer en 30 secondes.

Chez vous · 10 minutes

Installation sur votre serveur, clé en main

Pré-requis : un serveur Linux avec Docker installé, 4 Go de RAM minimum (8 Go recommandé), 20 Go de stockage libre. Une seule commande à coller : 

curl -fsSL https://raw.githubusercontent.com/kevinggraphiste-hub/Gungnir/main/install.sh | bash

Le script télécharge tout, génère les secrets, démarre Postgres, l'app et le sidecar de mise à jour. Vous accédez ensuite à http://votre-vps:8000 et créez votre compte admin. Les mises à jour se font ensuite toutes seules : un point vert apparaît quand une version sort, vous cliquez, c'est fait (retour arrière automatique si un problème est détecté).

Pour qui : données qui doivent rester chez vous (juridique, santé), plusieurs équipes, production stable.

Pour développeurs · 15 minutes

Installation à partir du code source

Vous récupérez le code et vous le compilez vous-même. Utile pour modifier Gungnir, ajouter vos propres modules, ou faire auditer le code ligne par ligne avant de déployer. 

git clone https://github.com/kevinggraphiste-hub/Gungnir.git
cd Gungnir
# créez le fichier .env (3 secrets requis : DATABASE_URL,
# GUNGNIR_SECRET_KEY, GUNGNIR_UPDATER_SECRET — voir INSTALL.md)
docker compose up -d --build

⚠ À savoir

Avec cette voie, vous gérez vous-même vos mises à jour. Scarlet Wolf ne peut pas garantir la compatibilité de vos modifications avec les versions futures. Pour rester couvert par les mises à jour automatiques, préférez l'installation clé en main ci-dessus.

Pour qui : développeurs qui veulent contribuer, audit de sécurité approfondi, modules privés.

Étapes 2 à 4 · Identiques pour tous
Étape 2 · 10 minutes

Faire connaissance

À la première connexion, votre assistant vous pose cinq questions, en conversation normale :

  • Le nom que vous voulez lui donner
  • S'il vous tutoie ou vous vouvoie
  • Son caractère (calme, direct, méthodique, etc.)
  • Sa liberté d'action (autonome, ou il demande avant d'agir)
  • S'il active sa mémoire tout de suite ou plus tard

Ce n'est pas un formulaire, c'est une vraie discussion. À la fin, votre assistant existe vraiment : avec son nom, son ton, son cadre.

Étape 3 · 15 minutes

Activer la mémoire long terme

C'est ce qui fait que votre assistant se souvient d'une fois sur l'autre. Vous créez un espace mémoire gratuit (1 Go inclus) sur cloud.qdrant.io, vous copiez les deux identifiants fournis dans Paramètres → Conscience, et c'est branché.

À partir de là, il retient vos préférences, votre contexte, les noms importants. D'une conversation à l'autre, d'une semaine à l'autre.

Étape 4 · à votre rythme

Brancher vos outils

Onglet Intégrations. En un clic et une autorisation, vous connectez Google (Gmail, Drive, Agenda, Contacts), Notion, Linear, ClickUp, Airtable, Slack, Discord, Telegram.

Pour aller plus loin, vous pouvez créer des automatisations et des compétences sur mesure. Le détail est sur la page Technique.

Gungnir s'adapte à votre métier. Il ne vous impose pas le sien.

Aller plus loin

Configurer, étendre, maintenir.

Vos propres modèles d'IA

Au-delà des 4 modèles offerts

Settings → Fournisseurs IA. Une clé API OpenRouter débloque 8 providers d'un coup ; vous pouvez aussi configurer Anthropic, OpenAI, Mistral directement. Pour le mode 100 % local, ajoutez Ollama (tourne sur votre machine, rien ne sort).

Marketplace

Modules de la communauté

Réglages → Marketplace. Parcourez les modules publiés par la communauté : voix premium, automatisations métier, intégrations spécialisées. Vous pouvez aussi publier les vôtres pour les partager.

Maintenance

Mises à jour et backups

Settings → Mises à jour active la vérification automatique (fetch GitHub toutes les 6 h). Quand une version sort, un point vert apparaît dans la sidebar, vous cliquez, le sidecar build et healthcheck (rollback auto en cas d'échec).

Settings → Backup exporte tout (utilisateurs, conversations, conscience, plugins, configs) en ZIP. Restoration en uploadant le ZIP. Compatible entre instances, vous pouvez migrer d'un VPS à un autre.
