Guide d'utilisation

Démarrer avec Gungnir.

Quatre étapes pour passer de "je découvre" à "il connaît mon métier". Compter trente minutes pour les trois premières.

L'étape 1 a trois voies au choix selon votre niveau de souveraineté : essai cloud immédiat, déploiement self-hosted clé en main, ou déploiement self-hosted en mode dev (avec accès au code source). Les étapes 2 à 4 sont identiques pour les trois.

Étape 1 · Choisir sa voie de démarrage
Voie A · 5 minutes · Cloud Scarlet Wolf

Essai 14 jours sur notre infrastructure

Rendez-vous sur gungnir.scarletwolf.cloud, choisissez l'option Essai 14 jours. Vous donnez une adresse email, rien d'autre. Pas de carte bancaire, pas de SIRET, pas de formulaire de qualification.

Vous démarrez avec quatre modèles gratuits OpenRouter pré-câblés (gpt-oss-120b, glm-4.5-air, laguna-m.1, nemotron-3-super-120b). Suffisant pour vous faire un avis sérieux.

Idéal pour : tester sans rien installer, valider que Gungnir couvre votre cas d'usage, démarrer en 30 secondes.

Voie B · 10 minutes · Self-hosted basique

Déploiement Docker clé en main sur votre VPS

Sur un VPS Linux avec Docker installé (4 Go RAM mini, 8 Go recommandé), une seule commande : 

curl -fsSL https://raw.githubusercontent.com/kevinggraphiste-hub/Gungnir/main/install.sh | bash

Le script crée un dossier gungnir/, génère les secrets, pull l'image Docker pré-buildée depuis GHCR, démarre Postgres + l'app + le sidecar updater. Vous accédez ensuite à http://votre-vps:8000 et créez votre compte admin.

Mises à jour : automatiques via le sidecar updater. Settings → Mises à jour → toggle "Vérification automatique" et c'est tout. Quand une nouvelle version sort, un point vert apparaît, vous cliquez, c'est fait (rollback auto si le healthcheck échoue).

Idéal pour : souveraineté complète (vos données chez vous), données sensibles (juridique, santé), instances multiples (par client / par département), production stable.

Voie C · 15 minutes · Self-hosted mode dev (avancé)

Build source sur votre VPS, code modifiable

Vous clonez le repo, vous buildez l'image localement. Idéal si vous voulez modifier le code, ajouter vos propres plugins en dur, ou auditer ligne par ligne avant déploiement. 

git clone https://github.com/kevinggraphiste-hub/Gungnir.git
cd Gungnir
# génère .env avec 3 secrets requis (voir INSTALL.md)
docker compose up -d --build

⚠ Disclaimer mode dev

En choisissant cette voie, vous prenez en charge vos propres mises à jour et la maintenance de votre fork. Scarlet Wolf ne peut pas garantir la compatibilité de vos modifications avec les versions futures de Gungnir, ni la sécurité des dépendances que vous ajoutez. Le sidecar updater automatique ne fonctionne pas sur le mode build source : c'est à vous de pull les nouveaux tags (git pull && docker compose up -d --build) et de gérer les conflits de merge si vous avez modifié le code core.

Pour rester sous garantie de mise à jour, restez sur la Voie B (image Docker pré-buildée, signée, mise à jour vérifiée).

Idéal pour : développeurs qui veulent contribuer ou forker, audit de sécurité approfondi par votre DSI, intégration de plugins privés non publiables sur la marketplace.

Étape 2 · 10 minutes

L'onboarding conversationnel

Au premier login, votre agent vous pose cinq questions, en conversation naturelle :

  • Le nom que vous voulez lui donner
  • S'il vous tutoie ou vous vouvoie
  • Sa personnalité (calme, direct, méthodique…)
  • Son mode d'autonomie (libre / demande la permission / restreint)
  • Sa conscience (Qdrant Cloud recommandé, Qdrant local, ou plus tard)

Pas un formulaire : une vraie conversation. À la fin, votre agent existe · avec son nom, son ton, son cadre.

Étape 3 · 15 minutes

Brancher la mémoire long-terme

Si vous avez choisi Qdrant Cloud à l'étape 2, créez un cluster gratuit (1 GB inclus) sur cloud.qdrant.io. Récupérez l'URL et la clé API, collez-les dans Paramètres → Conscience.

À partir de cet instant, votre agent se souvient. D'une conversation à l'autre, d'une semaine à l'autre. Il apprend vos préférences, votre contexte, les noms qu'il faut retenir.

Étape 4 · à votre rythme

Brancher vos outils

Onglet Intégrations. Connecteurs OAuth disponibles : Google (Gmail, Drive, Calendar, Chat, Contacts), Notion, Linear, ClickUp, Airtable, Slack, Discord, Telegram. Un clic, une autorisation, c'est branché.

Pour aller plus loin : créez vos workflows Forge (orchestration n8n native), ajoutez vos skills personnalisés, connectez vos canaux de notification (email, Telegram, widget web).

Gungnir s'adapte à votre métier. Il n'impose pas le sien.

Logs d'activité par utilisateur, exportables. Audit-ready RGPD. Plan de continuité documenté. Pour les équipes Compliance, deux instances Qdrant séparées (audit / contenu) avec isolation cryptographique.
