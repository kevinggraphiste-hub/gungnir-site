Guide d'utilisation

Démarrer avec Gungnir.

Quatre étapes pour passer de "je découvre" à "il connaît mon métier". Compter trente minutes pour les trois premières.

Étape 1 · 5 minutes

Créer un compte d'essai 14 jours

Rendez-vous sur gungnir.scarletwolf.cloud, choisissez l'option Essai 14 jours. Vous donnez une adresse email, rien d'autre. Pas de carte bancaire, pas de SIRET, pas de formulaire de qualification.

Vous démarrez avec quatre modèles gratuits OpenRouter pré-câblés (gpt-oss-120b, glm-4.5-air, laguna-m.1, nemotron-3-super-120b). Suffisant pour vous faire un avis sérieux.

Étape 2 · 10 minutes

L'onboarding conversationnel

Au premier login, votre agent vous pose cinq questions, en conversation naturelle :

  • Le nom que vous voulez lui donner
  • S'il vous tutoie ou vous vouvoie
  • Sa personnalité (calme, direct, méthodique…)
  • Son mode d'autonomie (libre / demande la permission / restreint)
  • Sa conscience (Qdrant Cloud recommandé, Qdrant local, ou plus tard)

Pas un formulaire : une vraie conversation. À la fin, votre agent existe — avec son nom, son ton, son cadre.

Étape 3 · 15 minutes

Brancher la mémoire long-terme

Si vous avez choisi Qdrant Cloud à l'étape 2, créez un cluster gratuit (1 GB inclus) sur cloud.qdrant.io. Récupérez l'URL et la clé API, collez-les dans Paramètres → Conscience.

À partir de cet instant, votre agent se souvient. D'une conversation à l'autre, d'une semaine à l'autre. Il apprend vos préférences, votre contexte, les noms qu'il faut retenir.

Étape 4 · à votre rythme

Brancher vos outils

Onglet Intégrations. Connecteurs OAuth disponibles : Google (Gmail, Drive, Calendar, Chat, Contacts), Notion, Linear, ClickUp, Airtable, Slack, Discord, Telegram. Un clic, une autorisation, c'est branché.

Pour aller plus loin : créez vos workflows Forge (orchestration n8n native), ajoutez vos skills personnalisés, connectez vos canaux de notification (email, Telegram, widget web).

Gungnir s'adapte à votre métier. Il n'impose pas le sien.

Pour utilisateurs avancés

Forge — workflows visuels

YAML d'abord, canvas React Flow ensuite. Chaîner des étapes (LLM, webhook, MCP, condition, attente humaine) pour automatiser des tâches métier répétitives. Compatible 100 % avec n8n.

Pour les DSI

Audit, logs, isolation

Logs d'activité par utilisateur, exportables. Audit-ready RGPD. Plan de continuité documenté. Pour les équipes Compliance, deux instances Qdrant séparées (audit / contenu) avec isolation cryptographique.

Une question pendant votre essai ?

Vous nous écrivez, on répond sous 24 h. Pas de chatbot de support qui vous fait tourner — un humain qui connaît le produit.
