Qu'est-ce que Gungnir

Une plateforme IA complète. Pas un chatbot.

Gungnir est une plateforme super-assistant full-stack : agent autonome configurable par utilisateur, conscience vectorielle persistante, 11 plugins modulaires (Forge pour les workflows, Valkyrie pour vos projets, SpearCode pour le code, conscience, voix temps réel, channels Telegram/Discord/Slack…), 14 providers LLM supportés.

Là où ChatGPT vous propose un compte et une mémoire courte, Gungnir vous donne votre instance, votre mémoire, vos plugins et le droit d'auditer chaque ligne de code qui touche vos données.

L'apprentissage continu existe partout. Le pilotage humain de cet apprentissage, non. C'est la signature Scarlet Wolf.

Différenciateur · Architecture cognitive

Soul, Skill, Personnalité : trois couches qui font la différence.

Là où la plupart des IA empilent des prompts dans une seule ficelle, Gungnir sépare trois couches indépendantes que vous pouvez régler séparément. C'est ce qui rend l'agent à la fois cohérent (une vraie identité) et flexible (compétences ciselées).

ᛞ
Couche 1

Soul · Qui il est

L'âme de votre agent. Sa formality (tu / vous), sa formation, ses convictions, ce qu'il valorise, comment il vous parle quand vous êtes fatigué. Posée à l'onboarding, évolue avec vous.

ᚱ
Couche 2

Skills · Ce qu'il sait faire

Chaque compétence est un module isolé : rédaction d'email, recherche jurisprudentielle, analyse de PDF, génération de code. Les skills se composent, s'améliorent par revue humaine, sans polluer l'identité.

ᛉ
Couche 3

Personnalité · Comment il agit

Le mode opératoire du moment. Calme et concis pour un brief client. Énergique et exploratoire pour du brainstorming. Vous bascule en un clic selon le contexte, sans réécrire son identité.

[ Schéma : empilement Soul + Skills + Personnalité → comportement agent ]

Résultat : un agent qui ne perd pas son identité quand il change de tâche, et qui ne change pas de compétence quand il change d'humeur.

Différenciateur · Souveraineté technique

100 % local possible. Sans compromis.

Sur les vraies données sensibles (juridiques, médicales, défense), le cloud est interdit. Gungnir tourne entièrement sur votre machine ou votre VPS, sans aucun appel externe.

  • LLM local via Ollama : Llama, Mistral, Qwen, Phi… modèles open-weight rapides
  • Mémoire vectorielle locale : Qdrant ou ChromaDB embarqués
  • Voix locale : Whisper.cpp pour la transcription, piper-tts pour la synthèse
  • Recherche locale : index full-text de vos documents, pas d'API web
  • Aucun télémétrique sortant : vérifiable au pare-feu

Démarrez avec les meilleurs modèles cloud pour la productivité, basculez en mode local quand vous traitez une affaire sensible. Le même agent. La même mémoire. La même interface.

Trois briques. Aucune dépendance impossible à briser.

Stack souveraine

  • Ollama : modèles locaux, option 100 % on-prem
  • Qdrant : mémoire vectorielle dédiée
  • OpenRouter : agrégation 8 providers LLM (cloud)
  • Forge (n8n natif) : orchestration workflows YAML
  • 9 providers de recherche : DuckDuckGo, Tavily, Brave, Exa…
  • 4 providers vocal : ElevenLabs, OpenAI Realtime, Gemini Live, Grok

Différenciateur · Symbiose métier

Valkyrie + Conscience : votre projet a enfin de la mémoire.

Valkyrie c'est votre suite project management interne (cards, sprints, kanban). La Conscience c'est votre mémoire vectorielle. Ensemble, elles donnent à l'agent la capacité d'organiser vos journées, de structurer vos projets, et de vous rappeler les urgences au bon moment.

Au matin

Brief du jour

L'agent ouvre la conversation par : « Bonjour. Trois deadlines cette semaine, dont une demain. Le dossier Martin attend toujours votre relecture. Voulez-vous qu'on le débloque maintenant ? »

Au détour d'une conversation

Rappels contextuels

Vous discutez du dossier Bernard. L'agent intercale : « Avant de continuer, rappel utile : Bernard demandait sa note d'honoraires pour jeudi. On la prépare en parallèle ? » Sans vous interrompre, sans spammer.

En continu

Structuration auto des projets

Quand vous évoquez une nouvelle affaire, l'agent crée la card Valkyrie, la lie aux contacts pertinents, classe les pièces jointes par type. Vous discutez normalement : la structure se construit derrière.
